# Tupitoons

Premium urban sleepwear storefront for Tupitoons.

## Current version

The first static storefront includes:

- Editorial hero and campaign image.
- Featured product drop with prototype prices.
- Collection filters and size selection.
- Editorial product detail modal with fit, material and care information.
- Local shopping bag with subtotal, quantity controls, removal and persistence.
- Free-shipping progress toward the prototype COP 250,000 threshold.
- Collection cards that filter the catalog and update its editorial context.
- Popcorn Sky Wide Leg campaign reference added as TUPI-007.
- Print library and collection storytelling.
- Newsletter interaction.
- Responsive layouts for desktop and mobile.

## Run locally

Serve the repository root with any static HTTP server and open the local URL.
For example:

```powershell
python -m http.server 4175
```

Open `http://127.0.0.1:4175/` in a browser.
